# Open Graph fonts

`NotoSansSC-Regular.ttf` and `NotoSansSC-Bold.ttf` are text subsets of Noto Sans
SC used only for the Simplified Chinese Open Graph image. They were generated by
the Google Fonts CSS API for the exact current Chinese heading and tagline:

```text
实时去中心化无需等待的 bitcoin 工作量证明。
```

The source family is Noto Sans SC from
`https://github.com/google/fonts/tree/main/ofl/notosanssc`. Its license is in
`NotoSansSC-OFL.txt`. The i18n test suite verifies that both subset weights cover
every visible character in the current Chinese Open Graph copy; regenerate the
subsets when that copy changes.

`MaShanZheng-Regular.ttf` is a text subset of Ma Shan Zheng used for the
Simplified Chinese desktop DAG annotation:

```text
实时 pow
```

The source family is Ma Shan Zheng from
`https://github.com/google/fonts/tree/main/ofl/mashanzheng`. Its license is in
`MaShanZheng-OFL.txt`. The same coverage gate protects this reviewed annotation
from silently falling back to a mismatched system font.

The Russian desktop DAG annotation uses the Cyrillic subset of Caveat through
`next/font`. Its source family is Caveat from
`https://github.com/google/fonts/tree/main/ofl/caveat` and remains subject to the
SIL Open Font License published with that family.
