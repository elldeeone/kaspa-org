# Local font assets

`NotoSansSC-Regular.ttf` and `NotoSansSC-Bold.ttf` are Google Fonts CSS API
subsets of [Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc)
for the Simplified Chinese Open Graph heading and tagline. Their license is in
`NotoSansSC-OFL.txt`.

`NotoSansJP-Regular.ttf` and `NotoSansJP-Bold.ttf` are Google Fonts CSS API
subsets of [Noto Sans JP](https://github.com/google/fonts/tree/main/ofl/notosansjp)
for the Japanese Open Graph heading and tagline. Noto Sans JP uses the same
Adobe Source SIL Open Font License included in `NotoSansSC-OFL.txt`.

`MaShanZheng-Regular.ttf` is a Google Fonts CSS API subset of
[Ma Shan Zheng](https://github.com/google/fonts/tree/main/ofl/mashanzheng) for
the Simplified Chinese DAG annotation. Its license is in
`MaShanZheng-OFL.txt`.

`Yomogi-Regular.ttf` is a Google Fonts CSS API subset of
[Yomogi](https://github.com/google/fonts/tree/main/ofl/yomogi) for the Japanese
DAG annotation. Its license is in `Yomogi-OFL.txt`.

The locale font contracts declare the exact translated characters covered by
these subsets. Regenerate a subset and update its contract when the associated
copy changes.
