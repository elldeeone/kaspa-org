# Open Graph fonts

`NotoSansSC-Regular.ttf` and `NotoSansSC-Bold.ttf` are text subsets of Noto Sans
SC used only for the Simplified Chinese Open Graph image. They were generated by
the Google Fonts CSS API for the exact current Chinese heading and tagline:

```text
实时去中心化无需等待的 bitcoin 工作量证明。
```

The source family is Noto Sans SC from
`https://github.com/google/fonts/tree/main/ofl/notosanssc`. Its license is in
`NotoSansSC-OFL.txt`. The i18n test suite verifies that both subset weights cover
every visible character in the current Chinese Open Graph copy; regenerate the
subsets when that copy changes.

`NotoSansJP-Regular.ttf` and `NotoSansJP-Bold.ttf` are text subsets of Noto Sans
JP used only for the Japanese Open Graph image in review Preview builds. The
subsets cover the exact reviewed Japanese heading and tagline, including their Latin text. They
come from the Google Fonts CSS API and use the Adobe Source SIL Open Font
License already included in `NotoSansSC-OFL.txt`. Glyph tests prevent a copy
change from silently falling back to another CJK font.

`MaShanZheng-Regular.ttf` is a text subset of Ma Shan Zheng used for the
Simplified Chinese desktop DAG annotation:

```text
实时 pow
```

The source family is Ma Shan Zheng from
`https://github.com/google/fonts/tree/main/ofl/mashanzheng`. Its license is in
`MaShanZheng-OFL.txt`. The same coverage gate protects this reviewed annotation
from silently falling back to a mismatched system font.

`Yomogi-Regular.ttf` is a text subset of Yomogi used for the Japanese desktop
DAG annotation in review Preview builds. Its source family is Yomogi from
`https://github.com/google/fonts/tree/main/ofl/yomogi`; its licence is in
`Yomogi-OFL.txt`. The Japanese annotation glyph gate covers kana, Latin text,
and punctuation in the reviewed copy.

The Russian desktop DAG annotation uses the Cyrillic subset of Caveat through
`next/font`. Its source family is Caveat from
`https://github.com/google/fonts/tree/main/ofl/caveat` and remains subject to the
SIL Open Font License published with that family.

```text
실시간 탈중앙화 기다림 없는 bitcoin의 작업 증명.
```

The source family is Noto Sans KR from
`https://github.com/google/fonts/tree/main/ofl/notosanskr`. Its license is in

`NotoSansKR-Body.ttf` is a variable-weight subset of the same OFL family. It
covers every Hangul character currently visible across all Korean catalogs and
is selected only by the `ko` document body. Other locales retain Geist and do
not request this asset. The exhaustive catalog-to-font coverage test must be
updated by regenerating the subset whenever Korean catalog copy adds a glyph.
